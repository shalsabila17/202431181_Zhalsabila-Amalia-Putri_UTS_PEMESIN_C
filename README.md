## Deskripsi
Proyek ini membahas pengenalan dan pengolahan dataset produksi kakao menurut provinsi di Indonesia periode 2020–2024.

## Sumber Dataset
Satu Data Pertanian – Kementerian Pertanian Republik Indonesia.

Link: https://satudata.pertanian.go.id/datasets/detail_data/531

## Tahapan Pengolahan
1. Membaca dan memahami dataset.
2. Mengidentifikasi missing value.
3. Mendeteksi outlier menggunakan metode IQR.
4. Melakukan data preprocessing.
5. Melakukan Exploratory Data Analysis (EDA).
6. Membangun model Regresi Linear Sederhana.
7. Melakukan evaluasi model menggunakan MAE, RMSE, dan R².
